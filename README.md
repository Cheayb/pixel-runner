# Pixel Runner

Simple 2D action platformer (HTML5). Run, jump and shoot enemies.

## Play
Open `index.html` in a browser, or enable GitHub Pages (Settings > Pages > main branch).

## Controls
- Touch: on-screen buttons
- Keyboard: arrows/WASD to move, Space/Up to jump, X/K to shoot

## Build APK
Use PWABuilder.com with your GitHub Pages URL, or Capacitor.
